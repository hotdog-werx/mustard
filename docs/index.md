# Mustard

Mustard measures project and patch coverage in GitHub Actions. Upload coverage
from your test jobs and aggregate it once to publish check runs, annotate
uncovered changed lines, and summarize the result on the pull request.

- [Install Mustard in your CI workflow](quick-start.md).
- [Choose project and patch coverage targets](configuration.md#checks).
